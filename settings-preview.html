Settings — icon rail, one section at a time

Rendered from the real Settings page (acrylic theme) with a throwaway vault and two throwaway instances, at the launcher window's own size (1480×820). The window was positioned off-screen for the capture, so the desktop backdrop's blur is not part of it — that only shows up in the running app. The Minecraft tab writes into every instance's own options.txt and re-applies it before each launch: the switch pins the Music slider to 0, and the number box pins guiScale to the number you pick instead of leaving it on Auto.
